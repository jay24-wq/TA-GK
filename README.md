# Bouncing Ball

Game 3D sederhana: bola dan limas jatuh, memantul di dalam wadah, lalu
pasangan dengan bentuk sama menghilang dan menambah skor.

## Fitur

- Wadah dan objek 3D dengan pencahayaan pada bola dan limas.
- Objek memantul pada enam sisi wadah.
- Seret area permainan untuk memutar tampilan wadah dan semua objek.
- Pasangan bentuk sama langsung menambah skor lalu menyusut selama 0,3 detik;
  tumbukan bentuk berbeda saling memantul.

## Kontrol

- **Mulai**: mulai simulasi.
- **Tambah Bola / Tambah Limas**: tambah sepasang objek sebelum mulai.
- **Ulangi**: mulai permainan baru.
- **Seret satu jari atau klik-tahan dan geser mouse di area permainan**:
  putar tampilan. Seret horizontal mengubah yaw; seret vertikal mengubah pitch.

Rotasi hanya mengubah tampilan, tidak mengubah koordinat atau aturan fisika.
